# Rating System React App

This is a simple React project created as part of my assignment.  
It allows users to select a star rating and view a message based on their selection.

## Features

- 5-star rating system  
- Dynamic rating text (Poor → Excellent)  
- Dialog box with "Thanks for rating" message  
- Clean and simple UI  

## Built With

- React  
- JSX 
- CSS  

## Project Structure

- `components/Star.js` → Single star component  
- `components/StarRating.js` → Handles rating logic  
- `components/Dialog.js` → Dialog popup  
- `css/index.css` → Main styling  
- `css/reset.css` → Reset styles  

## How to Run

1. Clone the repository  
2. Run `npm install`  
3. Run `npm start`
